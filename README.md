# BMI Calculator

## 📌 Project Description

This project is a Python-based BMI Calculator developed as part of the OASIS INFOBYTE Python Programming Internship.

The program takes the user's weight in kilograms and height in meters, calculates the Body Mass Index (BMI), and displays the corresponding BMI category.

## 🛠️ Technologies Used

- Python
- Python input()
- Basic Arithmetic
- if-elif-else
- Exception Handling

## ✨ Features

- Accepts weight in kilograms
- Accepts height in meters
- Calculates BMI using the formula:
  
  BMI = weight / (height²)

- Displays BMI rounded to 2 decimal places
- Classifies BMI into:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Validates invalid input
- Rejects negative or zero values
