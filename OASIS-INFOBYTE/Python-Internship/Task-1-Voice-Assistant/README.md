# Voice Assistant

## Project Description

A Python-based voice assistant that listens to spoken commands and responds with useful actions.

## Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- datetime
- webbrowser

## Features

- Voice input through microphone
- Greeting response
- Current time
- Current date
- Web search
- Text-to-speech responses
- Error handling for unclear voice input

## How to Run

Install the required libraries:

```bash
pip install SpeechRecognition
pip install pyttsx3
pip install PyAudio
