# Random Password Generator

## 📌 Project Description

This project is a Python-based Random Password Generator developed as part of the OASIS INFOBYTE Python Programming Internship.

The program allows users to generate random passwords based on their selected password length and character types.

## 🛠️ Technologies Used

- Python
- random module
- string module

## ✨ Features

- Minimum password length of 8 characters
- Allows the user to select character types:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Symbols
- Requires at least two character types
- Generates a random password
- Validates invalid input
- Handles non-numeric password length
- Allows users to generate another password without restarting the program

## 🔐 How It Works

1. The user enters the required password length.
2. The program checks that the length is at least 8 characters.
3. The user selects the character types to include.
4. The program validates the selected options.
5. A random password is generated using the selected character types.
6. The generated password is displayed on the screen.
7. The user can generate another password if required.
